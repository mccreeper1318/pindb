macOS user & install guide

This page covers macOS-specific setup. For creating databases, fields, records, backups, documents, printing, and general use, see the main PinDB User Guide.

Choose the correct package

  • Apple Silicon: use the -macos-arm64.pkg package.
  • Intel: use the -macos-x64.pkg package.

Install

  1. Download the matching PKG and checksum from PinDB for macOS.
  2. Verify the SHA-256 checksum.
  3. Open the verified PKG in Finder and complete installation in macOS Installer.
  4. If macOS displays a trust warning, approve only the verified official package through the normal system controls.
  5. Launch PinDB from Applications or open a registered .pindb file.

Verify the PKG

shasum -a 256 -c PinDB-<version>-macos-arm64.pkg.sha256
# or
shasum -a 256 -c PinDB-<version>-macos-x64.pkg.sha256

The command must report OK.

Application data

  • Configuration: ~/Library/Application Support/PinDB
  • State and diagnostics: ~/Library/Application Support/PinDB/State
  • Cache and update downloads: ~/Library/Caches/PinDB

Updates

PinDB selects the package for the current Mac architecture and verifies the published checksum before handing the package to macOS Installer. Follow the update instructions shown for the release you are installing.

Your databases

.pindb files are ordinary user documents. Keep separate external backups of important databases.
