Build PinDB on Debian-family Linux

Requirements

  • Git
  • JDK 25 with jpackage
  • Debian packaging tools required by jpackage

Clone and test

git clone https://github.com/mccreeper1318/pindb.git
cd pindb
git switch dev
chmod +x gradlew
./gradlew clean test

Run from source

./gradlew run

Create the DEB package

Replace <version> with the version you are building.

./gradlew clean test packageDeb -PappVersion=<version>

The package is written under build/packages/ and includes a private Java runtime.

Development branch

The website build instructions use the project's dev branch so contributors test current development code. Use a tagged release instead when reproducing a specific published version.
