Debian-family user & install guide

This page covers Debian, Ubuntu, Linux Mint, and related Debian-family systems. For normal application use, see the main PinDB User Guide.

Install

  1. Download the DEB and its checksum from PinDB for Debian-family Linux.
  2. Verify the checksum.
  3. Install the package with APT.
sha256sum -c downloaded-package.deb.sha256
sudo apt install ./pindb_*_amd64.deb

The native package is self-contained and includes PinDB's Java runtime.

Updates

On supported traditional Debian-family systems, PinDB verifies the matching DEB before requesting administrator approval and handing installation to the packaged update helper and native package manager.

Uninstall

sudo apt remove pindb

Removing the application package does not remove separately stored .pindb database files.

Your databases

Close a database normally before manually copying it. Keep external backups of important databases in addition to PinDB's internal snapshots.
