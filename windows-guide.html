Windows user & install guide

This page covers Windows-specific setup. For creating databases, fields, records, backups, documents, printing, and general use, see the main PinDB User Guide.

Install

  1. Download the stable or preview x64 EXE and its checksum from PinDB for Windows.
  2. Compare the installer SHA-256 value with the published checksum.
  3. Run the installer and follow the prompts.
  4. Launch PinDB from the Start Menu or open a registered .pindb file.

Verify with PowerShell

Get-FileHash .\PinDB-<version>-windows-x64.exe -Algorithm SHA256
Get-Content .\PinDB-<version>-windows-x64.exe.sha256
Security prompts: signing status can vary by release. If Windows shows an unknown-publisher or SmartScreen warning, verify the checksum first and proceed only with the official GitHub Release asset you intended to download.

Application data

  • Configuration: %APPDATA%\PinDB
  • State and cache: %LOCALAPPDATA%\PinDB

Updates

PinDB can download the matching x64 installer and verify its checksum before handing off to the Windows installer. Complete the installer normally when prompted.

Your databases

.pindb files are user documents, not part of the application installation. Keep external backups of important databases.
