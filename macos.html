Which package do I need?

MacPackage suffix
Apple Silicon-macos-arm64.pkg
Intel-macos-x64.pkg

Use Apple menu → About This Mac if you are unsure which processor your Mac uses.

Package trust: signing and notarization status can vary by release. Always download the package and checksum from the same official GitHub Release and verify the checksum before approving any macOS security prompt.

Verify a download

shasum -a 256 -c PinDB-<version>-macos-arm64.pkg.sha256
# or
shasum -a 256 -c PinDB-<version>-macos-x64.pkg.sha256

The command must report OK.

Updates

PinDB selects only the package matching the current Mac architecture, verifies SHA-256, prepares the verified package for Installer handoff, and opens macOS Installer. Follow the prompts shown by the current release.
