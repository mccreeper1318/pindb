Build from source

PinDB uses the Gradle wrapper and Java 25. Choose the build page for the operating system where you plan to compile or package the application.

Windows

Run and package PinDB on supported 64-bit Windows systems.

Windows source build

macOS

Build native Apple Silicon or Intel packages on matching Mac hardware.

macOS source build

Debian family

Build and package DEB releases on Debian-family Linux.

Debian source build

Fedora family

Build and package RPM releases on Fedora-family Linux.

Fedora source build

Shared requirements

  • Git
  • JDK 25, including jpackage for native packaging
  • Platform-native packaging tools when creating installers

The Gradle wrapper is included in the repository, so a separate Gradle installation is not required.

Repository

git clone https://github.com/mccreeper1318/pindb.git
cd pindb
git switch dev

Use the platform page above for the appropriate test, run, and package commands.
