Build PinDB From Source

PinDB is a Java 21 application built with Gradle and JavaFX.

Requirements

  • Git
  • JDK 21
  • Internet access for Gradle dependency downloads
  • Linux, jpackage, dpkg, and fakeroot to build the official Debian package

Clone and test

git clone https://github.com/mccreeper1318/pindb.git
cd pindb
chmod +x gradlew
./gradlew clean test

Run from source

./gradlew run

Build the Debian package

./gradlew clean test packageDeb -PappVersion=0.2-beta.3

The package is written to:

build/packages/

Open in IntelliJ IDEA

  1. Open the cloned repository as a Gradle project.
  2. Set both the project SDK and Gradle JVM to JDK 21.
  3. Allow Gradle to load the dependencies.
  4. Run the Gradle run task or org.pindb.PinDBLauncher.

Contributing

Keep changes focused, run ./gradlew clean test, and do not commit databases or documents containing private information.
