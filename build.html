Build PinDB From Source

PinDB is a Java 21 application built with Gradle and JavaFX.

General requirements

  • Git
  • JDK 21 with jpackage
  • Internet access for Gradle dependency downloads
  • A 64-bit Linux build system

Package-specific requirements

PackageBuild system and tools
Debian .debDebian-family Linux with dpkg, dpkg-deb, and fakeroot
Fedora .rpmFedora or another RPM-based build system with rpm-build and rpmbuild

Native jpackage installers should be built on a system from the corresponding package family.

Clone and test

git clone https://github.com/mccreeper1318/pindb.git
cd pindb
chmod +x gradlew
git switch agent/0.2-dev
./gradlew clean test

Run from source

./gradlew run -PappVersion=0.2-beta.4

Build the Debian package

./gradlew clean test packageDeb -PappVersion=0.2-beta.4

Build the Fedora RPM

On Fedora, install the native RPM packaging tools and use a JDK 21 distribution that includes jpackage.

sudo dnf install rpm-build desktop-file-utils cpio
./gradlew clean test packageRpm -PappVersion=0.2-beta.4

Both package tasks write their output to:

build/packages/

Inspect the RPM

rpm -qpi build/packages/*.rpm
rpm -qpl build/packages/*.rpm

The package should include the PinDB launcher, private Java runtime, desktop entry, icon, and .pindb file association.

Automated builds

The GitHub Actions build workflow tests and packages both formats independently:

  • The Debian package is built on Ubuntu.
  • The RPM is built inside a Fedora container using Temurin Java 21.
  • The RPM metadata, desktop entry, launcher reference, and icon are checked before the artifact is accepted.

The release workflow creates a checksum for each package and attaches both packages and both checksum files to the GitHub Release.

Open in IntelliJ IDEA

  1. Open the cloned repository as a Gradle project.
  2. Set both the project SDK and Gradle JVM to JDK 21.
  3. Allow Gradle to load the dependencies.
  4. Run the Gradle run task or org.pindb.PinDBLauncher.

Contributing

Keep changes focused, run ./gradlew clean test, and do not commit databases or documents containing private information.
