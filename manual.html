Create a database

  1. Launch PinDB.
  2. Select Create New Database.
  3. Name the database and choose where its .pindb file should live.
  4. Add the fields needed for the information you want to track.
  5. Create the database and use the + button to add entries.

Open existing databases

Use the launcher and recent-files list, or open a registered .pindb file from your operating system's file manager.

Fields

PinDB supports text, multiline text, number, currency, date, date/time, yes/no, dropdown, and embedded-document fields. Depending on the field type, you can configure requirements, defaults, ranges, uniqueness, text limits, choices, and summaries.

Organize records

  • Search visible data.
  • Sort table columns.
  • Create field-specific filters.
  • Switch between table and record views.
  • Use Add & Add Another for repetitive entry.
  • Recover records from Recently Deleted before permanent removal.

Embedded documents

Document fields store the original file inside the database. Supported files can be previewed, saved as copies, printed where available, or opened with the system application.

Backups and transfer

PinDB keeps internal logical snapshots for recovery, but important databases should also be backed up separately. Close the database normally before manually copying or moving its .pindb file.

Updates

PinDB can check GitHub Releases for stable updates, with preview releases available when enabled in Settings. The exact package and installation flow differ by platform, so use the relevant platform guide above.

Report a bug

Use Report Bug from the launcher or Help → Report a Bug…. GitHub device authorization is used for sign-in. PinDB does not automatically attach database contents, embedded documents, database filenames, or personal file paths.
