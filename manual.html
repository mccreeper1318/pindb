User Guide

1. Create a database

  1. Launch PinDB.
  2. Select Create New Database.
  3. Name the database and choose where the .pindb file should be saved.
  4. Add the fields you need.
  5. Select Create Database.

2. Add entries

Use the + button to add a record. Complete the fields and select Add Entry. Use Add & Add Another when entering several records in a row.

3. Find information

Use the search box for a broad search. Select a column heading to sort. Use field filters to display records matching specific values.

4. Store documents

Add a Document field, edit a record, and choose the file. The original file is copied into the .pindb database. Click its filename later to preview or save it.

5. Back up your database

PinDB keeps internal snapshots, but those snapshots are part of the same database file. Copy important .pindb files to another drive or backup service.

6. Update PinDB

PinDB checks GitHub Releases for newer versions. Stable releases are selected by default. Beta updates can be enabled in Settings.

Frequently asked questions

Do I need a database server?
No. Each database is a local SQLite file.
Do I need Java?
Not when installing the official .deb. It includes a private runtime.
Are database contents encrypted?
No. The current version does not encrypt database contents.
Can I move a database?
Yes. Close it in PinDB, then copy the entire .pindb file.
