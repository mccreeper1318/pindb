User Guide

1. Install PinDB

Choose the package that matches your computer:

  • .exe for 64-bit Windows 11, beginning with the 0.3 Beta 1 preview.
  • .deb for Linux Mint, Ubuntu, Debian, and related systems.
  • .rpm for Fedora Workstation, Fedora KDE, and traditional Fedora spins.

Every official package includes its own Java runtime. See the Download page for package links. Detailed guides are available for Windows, Debian-family systems, and Fedora.

2. Create a database

  1. Launch PinDB.
  2. Select Create New Database.
  3. Name the database and choose where the .pindb file should be saved.
  4. Add the fields you need.
  5. Select Create Database.

3. Add entries

Use the + button to add a record. Complete the fields and select Add Entry. Use Add & Add Another when entering several records in a row.

4. Find information

Use the search box for a broad search. Select a column heading to sort. Use field filters to display records matching specific values.

5. Store documents

Add a Document field, edit a record, and choose the file. The original file is copied into the .pindb database. Click its filename later to preview, print, save a copy, or open it in another application.

6. Back up your database

PinDB keeps internal snapshots, but those snapshots are part of the same database file. Copy important .pindb files to another drive or backup service. Close the database before making an external copy.

7. Update PinDB

PinDB checks GitHub Releases for newer versions. Stable releases are selected by default; preview updates can be enabled in Settings.

PinDB selects the native package for the current operating system and architecture and verifies the matching published SHA-256 checksum before installation.

SystemUpdate method
Windows 11 x64Downloads and verifies the matching .exe, then launches the per-user installer after approval.
Debian / Ubuntu / Linux MintAutomatic .deb installation with apt-get through the packaged privileged helper.
Traditional Fedora systemsAutomatic .rpm installation with dnf5 or dnf through the packaged privileged helper.

Frequently asked questions

Do I need a database server?
No. Each database is a local SQLite file.
Do I need Java?
Not when installing an official .exe, .deb, or .rpm. Each includes a private runtime.
Why does Windows warn about the installer?
The current Windows preview installer is unsigned. Download it only from the official GitHub Release and verify its SHA-256 checksum before deciding whether to run it.
Which Fedora editions are supported?
The normal RPM is intended for Fedora Workstation, Fedora KDE, and traditional Fedora spins. Atomic desktops require manual rpm-ostree installation.
Are database contents encrypted?
No. The current version does not encrypt database contents.
Can I move a database between Windows and Linux?
Yes. Close it in PinDB, then copy the complete .pindb file. The database format is portable across supported systems.
