User Guide

1. Install PinDB

Choose the package that matches your Linux system:

  • .deb for Linux Mint, Ubuntu, Debian, and related systems.
  • .rpm for Fedora Workstation, Fedora KDE, and traditional Fedora spins.

Both packages include their own Java runtime. See the Download page for package links and installation commands. Fedora users can read the complete Fedora guide and Debian users can read the complete Debian guide.

2. Create a database

  1. Launch PinDB.
  2. Select Create New Database.
  3. Name the database and choose where the .pindb file should be saved.
  4. Add the fields you need.
  5. Select Create Database.

3. Add entries

Use the + button to add a record. Complete the fields and select Add Entry. Use Add & Add Another when entering several records in a row.

4. Find information

Use the search box for a broad search. Select a column heading to sort. Use field filters to display records matching specific values.

5. Store documents

Add a Document field, edit a record, and choose the file. The original file is copied into the .pindb database. Click its filename later to preview, print, save a copy, or open it in another application.

6. Back up your database

PinDB keeps internal snapshots, but those snapshots are part of the same database file. Copy important .pindb files to another drive or backup service.

7. Update PinDB

PinDB checks GitHub Releases for newer versions. Stable releases are selected by default. Beta updates can be enabled in Settings.

On supported systems, PinDB selects the correct package, verifies the checksum when supplied, requests administrator approval, installs the update, restarts, and displays the release notes.

SystemUpdate method
Debian / Ubuntu / Linux MintAutomatic .deb installation with apt-get
Traditional Fedora systemsAutomatic .rpm installation with dnf5 or dnf
Fedora Silverblue / Kinoite / AtomicManual rpm-ostree installation and reboot

Frequently asked questions

Do I need a database server?
No. Each database is a local SQLite file.
Do I need Java?
Not when installing the official .deb or .rpm. Both include a private runtime.
Which Fedora editions are supported?
The normal RPM is intended for Fedora Workstation, Fedora KDE, and traditional Fedora spins. Atomic desktops require manual rpm-ostree installation.
Are database contents encrypted?
No. The current version does not encrypt database contents.
Can I move a database between Debian and Fedora?
Yes. The .pindb format is portable. Close the database, then copy the complete file.
Can I move a database?
Yes. Close it in PinDB, then copy the entire .pindb file.
