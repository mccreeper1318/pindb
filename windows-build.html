Build PinDB on Windows

Requirements

  • 64-bit Windows development environment
  • Git
  • JDK 25 with jpackage
  • WiX Toolset when creating the native EXE installer

Clone and test

git clone https://github.com/mccreeper1318/pindb.git
cd pindb
git switch dev
gradlew.bat clean test

Run from source

gradlew.bat run

Create the Windows installer

Replace <version> with the version you are building, such as a release or prerelease version supported by the project.

gradlew.bat clean test packageWindows -PappVersion=<version>

The packaged output is written under build/packages/. The native package includes a private Java runtime.

Release behavior

Official Windows release assets are built by the project's Windows release workflow. Local builds are intended for development and verification unless you are following the repository's release process.
