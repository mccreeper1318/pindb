Fedora user & install guide

This page covers Fedora Workstation, Fedora spins, and Fedora Atomic variants. For normal application use, see the main PinDB User Guide.

Traditional Fedora

  1. Download the RPM and checksum from PinDB for Fedora.
  2. Verify the checksum.
  3. Install with DNF.
sha256sum -c downloaded-package.rpm.sha256
sudo dnf install ./pindb-*.x86_64.rpm

Updates on traditional Fedora

PinDB verifies the matching RPM before requesting administrator approval and handing installation to the packaged update helper and dnf5 or dnf.

Fedora Atomic

Silverblue, Kinoite, and other immutable variants require manual package layering:

sudo rpm-ostree install ./pindb-*.x86_64.rpm

Reboot into the new deployment after installation or update.

Uninstall

Traditional Fedora:

sudo dnf remove pindb

For an Atomic system, use the matching rpm-ostree removal workflow and reboot into the resulting deployment.

Your databases

Removing PinDB does not remove separately stored .pindb database files. Keep external backups of important data.
