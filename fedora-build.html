Build PinDB on Fedora

Requirements

  • Git
  • JDK 25 with jpackage
  • RPM packaging tools required by jpackage

Clone and test

git clone https://github.com/mccreeper1318/pindb.git
cd pindb
git switch dev
chmod +x gradlew
./gradlew clean test

Run from source

./gradlew run

Create the RPM package

Replace <version> with the version you are building.

./gradlew clean test packageRpm -PappVersion=<version>

The RPM is written under build/packages/ and includes a private Java runtime. Building an RPM and installing it on Fedora Atomic are separate concerns; Atomic installation still follows its rpm-ostree workflow.

Development branch

The website build instructions use the project's dev branch so contributors test current development code. Use a tagged release instead when reproducing a specific published version.
