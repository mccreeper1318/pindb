Windows user & install guide Build for Windows

Package information

The Windows package is an x64 .exe installer. It installs PinDB per-user, integrates with the Start Menu, can create a desktop shortcut, and registers .pindb files.

Installer trust: if Windows reports an unknown publisher or SmartScreen warning, verify the SHA-256 checksum from the same GitHub Release before running the installer. Signing status can vary by release.

Verify a download

Get-FileHash .\PinDB-<version>-windows-x64.exe -Algorithm SHA256
Get-Content .\PinDB-<version>-windows-x64.exe.sha256

The hexadecimal values must match.

Updates

PinDB selects the matching Windows installer, verifies its published SHA-256 checksum, launches the verified installer, and exits so the installed application can be replaced.
