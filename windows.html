Windows 11 x64

Download the PinDB-<version>-windows-x64.exe and matching checksum from the Download page.

Unsigned installer: Windows may show an unknown-publisher or SmartScreen warning. Verify the SHA-256 digest before running the installer.
Get-FileHash .\PinDB-<version>-windows-x64.exe -Algorithm SHA256
Get-Content .\PinDB-<version>-windows-x64.exe.sha256

The installer is self-contained, installs per-user, provides Start Menu integration, can create a desktop shortcut, and registers .pindb files.

Updates

PinDB downloads and checksum-verifies the matching x64 EXE, launches the verified installer, then exits so the installer can replace the application.

Application data

  • Configuration: %APPDATA%\PinDB
  • State/cache: %LOCALAPPDATA%\PinDB
