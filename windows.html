Windows 11 Installation Guide

Windows support begins with PinDB 0.3 Beta 1 for 64-bit Windows 11.

System requirements

  • 64-bit Windows 11 on an x64 processor.
  • Permission to install an application for your Windows user account.
  • No separate Java installation; the installer includes a private Java 25 runtime.

Before running the installer

The Windows installer is currently unsigned. Windows cannot verify a named software publisher and may show an unknown-publisher or Microsoft Defender SmartScreen reputation warning. This does not by itself mean the file is malicious, but it removes the identity assurance supplied by a code-signing certificate.

  1. Download the .exe and matching .sha256 file only from the official PinDB 0.3 Beta 1 GitHub Release.
  2. Open PowerShell in the download folder.
  3. Run both commands below and confirm that the hexadecimal hashes match.
Get-FileHash .\PinDB-0.3-beta.1-windows-x64.exe -Algorithm SHA256
Get-Content .\PinDB-0.3-beta.1-windows-x64.exe.sha256

If SmartScreen blocks the verified installer, review the file name and source, select More info, and choose Run anyway only if you are comfortable proceeding.

Install PinDB

  1. Run the verified PinDB-0.3-beta.1-windows-x64.exe installer.
  2. Choose the installation folder and whether to create a desktop shortcut.
  3. Complete the per-user installation.
  4. Open PinDB from the Start Menu.

The installer associates .pindb files with PinDB, allowing a database to be opened directly from File Explorer.

Application data

PinDB follows Windows application-data conventions. Configuration is kept under the user's roaming application-data location referenced by %APPDATA%. State, caches, and downloaded update files use the local application-data location referenced by %LOCALAPPDATA%. Your database files remain wherever you choose to save them.

Updates on Windows

When Windows preview updates are enabled, PinDB can find the matching Windows x64 .exe, download it to the local application cache, require and verify its published SHA-256 checksum, and launch the verified installer after approval. Windows updates do not use the Linux privileged-update helper.

Uninstall

  1. Open Settings → Apps → Installed apps.
  2. Find PinDB.
  3. Open its menu and select Uninstall.

Uninstalling the application does not delete .pindb database files saved in your own folders. Keep an external backup of important databases.

Troubleshooting

The download button is unavailable.
The Windows installer asset has not yet been attached to the 0.3 Beta 1 release. Use the stable Linux packages if appropriate or check the GitHub Release again later.
Windows says the publisher is unknown.
The current installer is unsigned. Verify the SHA-256 checksum and confirm the download came from the official PinDB repository before deciding whether to continue.
A database does not open by double-clicking.
Start PinDB from the Start Menu and open the file from the launcher. Reinstalling can restore the .pindb file association.
