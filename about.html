About PinDB

PinDB makes small personal databases approachable for people who do not want to design SQL tables or maintain a server.

The application uses JavaFX for its interface and SQLite for portable database storage.

Windows and Linux support

PinDB provides self-contained native packages for three supported platform families:

  • .exe for 64-bit Windows 11, beginning with the 0.3 Beta 1 preview.
  • .deb for Linux Mint, Ubuntu, Debian, and related systems.
  • .rpm for Fedora Workstation, Fedora KDE, and traditional Fedora spins.

Every official package includes a private Java runtime. Databases use the same portable .pindb format across supported systems.

Windows preview

The Windows 11 package installs per-user and provides Start Menu integration, optional desktop shortcuts, installation-folder selection, and .pindb file associations. The current installer is unsigned, so Windows may display an unknown-publisher or SmartScreen reputation warning.

Fedora Atomic desktops

Silverblue, Kinoite, and other Atomic desktops can layer the RPM manually with rpm-ostree. PinDB does not attempt to run its normal DNF automatic installer on those immutable systems.

Important notice

PinDB is an early-stage application. Keep external backups of important databases. Verify exported and printed information before relying on it for legal, medical, tax, or financial records.
