About PinDB

PinDB is an open-source desktop personal database focused on portability, approachable data entry, local ownership, and native desktop use. It is intended for people who need more structure than a spreadsheet but do not want to run or administer a separate database server.

Project principles

  • Local-first: databases are files you choose and control.
  • Portable: a closed .pindb file can be copied, backed up, and moved like an ordinary file.
  • Approachable: common database tasks are exposed through a desktop interface instead of SQL.
  • Cross-platform: native packaging is provided for supported Windows, macOS, Debian-family, and Fedora-family systems.
  • Open source: development, issues, releases, and source code are public on GitHub.

Privacy and local data

PinDB does not require a hosted database service. User databases remain local unless the user chooses to copy or sync them elsewhere. The in-app bug reporter is designed not to automatically include database contents, embedded files, database filenames, document filenames, or personal file paths.

What belongs in a platform page

Installation requirements, package formats, signing status, update behavior, and current release downloads can differ by operating system. Those details are intentionally kept on the platform-specific download and guide pages so this page remains useful across release lines.

Current limitations

  • Database encryption is not yet built in.
  • Package signing and operating-system trust prompts may vary by platform and release.
  • Some immutable Linux distributions require manual package-management steps.
  • Embedded previews are intended for convenient inspection rather than full office-suite fidelity.
