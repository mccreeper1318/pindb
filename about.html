About PinDB

PinDB is an open-source desktop personal database focused on portable files, approachable data entry, embedded documents, and native desktop packaging without requiring a separate database server.

Current release lines

LinePurpose
0.2.1Current stable Linux-focused release line.
0.3Cross-platform development line adding Windows 11 and first-class macOS support alongside Linux.

0.3 platform status

  • Windows 11 x64: self-contained EXE, file association, native paths, checksummed updates, and Windows CI/release automation.
  • macOS Apple Silicon and Intel: self-contained PKGs, Finder association, native paths, architecture-matched protected updates, two-architecture CI, and automatic release assets.
  • Debian family: self-contained DEB with secure privileged updater.
  • Fedora traditional: self-contained RPM with DNF update support.
  • Fedora Atomic: manual rpm-ostree installation/update.
Signing status: PinDB 0.3 macOS PKGs are currently unsigned and not notarized. Windows installers are also currently unsigned. Verify published SHA-256 checksums before installation.

Privacy and local data

Databases are local files chosen by the user. PinDB does not require a hosted database service. The in-app bug reporter is designed not to automatically include database contents, embedded files, database filenames, document filenames, or personal file paths.

Limitations

  • Database encryption is not yet included.
  • Mac packages are not yet signed/notarized.
  • Windows packages are not yet code-signed.
  • Fedora Atomic updates require manual rpm-ostree handling.
  • Embedded previews are intended for convenient inspection rather than full office-suite fidelity.
