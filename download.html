Install on Windows 11

  1. Download the Windows x64 .exe and its matching .sha256 file when they are available.
  2. Verify the installer checksum as shown below.
  3. Run the installer and choose the installation folder and shortcut options.
  4. Launch PinDB from the Start Menu or open a .pindb file from File Explorer.

Unsigned installer: The 0.3 Beta 1 Windows installer is not code-signed. Windows may show an unknown-publisher or Microsoft Defender SmartScreen reputation warning. Only use the installer downloaded from the official PinDB GitHub Release, verify its SHA-256 checksum, and review the warning before choosing More info → Run anyway.

READ THE COMPLETE WINDOWS GUIDE

Install on Debian, Ubuntu, or Linux Mint

  1. Download the matching .deb file.
  2. Double-click it and open it with Software Manager or Package Installer.
  3. Select Install and enter your administrator password.
  4. Launch PinDB from the application menu.

Terminal installation:

sudo apt install ./pindb_*_amd64.deb

READ THE COMPLETE DEBIAN GUIDE

Install on Fedora Workstation or a traditional Fedora spin

  1. Download the matching .rpm file.
  2. Double-click it and open it with Software or Discover.
  3. Select Install and approve the administrator prompt.
  4. Launch PinDB from the application menu.

Terminal installation:

sudo dnf install ./pindb-*.x86_64.rpm

READ THE COMPLETE FEDORA GUIDE

Fedora Silverblue, Kinoite, and other Atomic desktops

PinDB does not perform automatic DNF updates on Fedora Atomic desktops. Install or update the RPM manually with rpm-ostree, then reboot into the new deployment.

sudo rpm-ostree install ./pindb-*.x86_64.rpm

Automatic application updates

PinDB can select the correct native package, download it, and verify its published SHA-256 checksum before starting the platform-specific update process.

SystemUpdate method
Windows 11 x64Downloads and verifies the matching .exe, then launches the per-user installer after approval.
Debian / Ubuntu / Linux MintInstalls the .deb with apt-get through the packaged privileged helper.
Fedora Workstation and traditional spinsInstalls the .rpm with dnf5 or dnf through the packaged privileged helper.
Fedora Atomic desktopsManual rpm-ostree installation and reboot required.

Verify a download

Download the checksum file that matches the package and compare it before installation.

Windows PowerShell:

Get-FileHash .\PinDB-0.3-beta.1-windows-x64.exe -Algorithm SHA256
Get-Content .\PinDB-0.3-beta.1-windows-x64.exe.sha256

The hexadecimal values should match. Linux:

sha256sum -c downloaded-package.deb.sha256
sha256sum -c downloaded-package.rpm.sha256

The Linux command should report OK.
