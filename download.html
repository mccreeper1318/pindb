Download PinDB

Official installers are published on GitHub Releases. Every native package includes its own Java runtime.

Before installing on macOS: PinDB 0.3 Mac PKGs are unsigned and not notarized. Download the PKG and matching .sha256 from the same official release, verify the checksum, and approve only that verified package through the normal macOS security controls. Do not disable Gatekeeper globally.

Which Mac download do I need?

MacPackage suffix
Apple Silicon (M1/M2/M3/M4 and newer M-series)-macos-arm64.pkg
Intel-macos-x64.pkg

On macOS choose Apple menu → About This Mac if you are unsure which processor your Mac uses.

Verify the download

macOS

shasum -a 256 -c PinDB-<version>-macos-arm64.pkg.sha256
# or
shasum -a 256 -c PinDB-<version>-macos-x64.pkg.sha256

The command must report OK.

Windows PowerShell

Get-FileHash .\PinDB-<version>-windows-x64.exe -Algorithm SHA256
Get-Content .\PinDB-<version>-windows-x64.exe.sha256

The hexadecimal values must match.

Linux

sha256sum -c downloaded-package.sha256

Installation summary

macOS

  1. Verify the PKG checksum.
  2. Open the verified PKG in Finder.
  3. If macOS blocks the unsigned package, approve that specific package through the normal warning or System Settings → Privacy & Security.
  4. Complete installation in macOS Installer.
  5. Launch PinDB from Applications/Finder. .pindb files can then be opened directly from Finder.

Windows 11

Verify the checksum, run the x64 EXE, and follow the installer. The current EXE is unsigned and can trigger an unknown-publisher/SmartScreen warning.

Debian family

sudo apt install ./pindb_*_amd64.deb

Fedora traditional

sudo dnf install ./pindb-*.x86_64.rpm

Fedora Atomic

sudo rpm-ostree install ./pindb-*.x86_64.rpm

Reboot into the new deployment after installation/update.

Update behavior

PlatformIn-app update behavior
Windows 11 x64Downloads and verifies the matching EXE, launches it, then exits.
macOS Apple Silicon / IntelSelects only the matching PKG, verifies SHA-256, stages a protected root-owned copy with administrator approval, opens macOS Installer, then exits. Reopen PinDB manually after Installer finishes.
Debian familyVerifies and installs the DEB through PinDB's fixed privileged helper and apt-get.
Fedora traditionalVerifies and installs the RPM through the fixed helper and dnf5/dnf.
Fedora AtomicManual rpm-ostree update and reboot required.
