Install on Debian, Ubuntu, or Linux Mint

  1. Download the matching .deb file.
  2. Double-click it and open it with Software Manager or Package Installer.
  3. Select Install and enter your administrator password.
  4. Launch PinDB from the application menu.

Terminal installation:

sudo apt install ./pindb_*_amd64.deb

READ THE COMPLETE DEBIAN GUIDE

Install on Fedora Workstation or a traditional Fedora spin

  1. Download the matching .rpm file.
  2. Double-click it and open it with Software or Discover.
  3. Select Install and approve the administrator prompt.
  4. Launch PinDB from the application menu.

Terminal installation:

sudo dnf install ./pindb-*.x86_64.rpm

Fedora Silverblue, Kinoite, and other Atomic desktops

PinDB does not perform automatic DNF updates on Fedora Atomic desktops. Install or update the RPM manually with rpm-ostree, then reboot into the new deployment.

sudo rpm-ostree install ./pindb-*.x86_64.rpm

Automatic application updates

On supported traditional Linux installations, PinDB can select the correct package type for the current system, download the package, verify its SHA-256 checksum when supplied, request administrator approval, install it, restart, and display the release notes.

SystemAutomatic installer
Debian / Ubuntu / Linux Mintapt-get through pkexec
Fedora Workstation and traditional spinsdnf5 or dnf through pkexec
Fedora Atomic desktopsManual rpm-ostree installation required

Verify a download

Download the checksum file that matches the package. Run the command from the folder containing both files:

sha256sum -c downloaded-package.deb.sha256
sha256sum -c downloaded-package.rpm.sha256

The check should report OK before installation.
