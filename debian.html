PinDB on Debian, Ubuntu, and Linux Mint

Use the self-contained DEB package for Debian-family Linux systems.

PinDB provides a 64-bit .deb package for Debian, Ubuntu, Linux Mint, and related distributions. The package includes a private Java runtime, so Java does not need to be installed separately for normal use.

GO TO DEBIAN DOWNLOADS

Install graphically

  1. Download the PinDB .deb from the Download page.
  2. Double-click the package and open it with Software Manager, GDebi, Discover, or your distribution's package installer.
  3. Select Install and enter your administrator password.
  4. Launch PinDB from the application menu.

Install from a terminal

sudo apt install ./pindb_*_amd64.deb

Using apt install instead of dpkg -i allows APT to resolve package requirements automatically.

Automatic updates

On supported Debian-family installations, PinDB can download the matching DEB package, verify its SHA-256 checksum when one is supplied, request administrator approval through pkexec, and install it with apt-get.

Stable updates are checked by default. Beta updates can be enabled in PinDB Settings.

Verify the downloaded DEB

Download the matching .sha256 file from the release and run:

sha256sum -c pindb_*.deb.sha256

The check should report OK before you install the package.

What the DEB installs

  • The PinDB application and private Java runtime under /opt/pindb.
  • An application-menu shortcut.
  • The PinDB application icon.
  • A file association for .pindb databases.

Upgrade PinDB manually

Download the newer DEB and install it using the same graphical method or terminal command. The package upgrades the application without deleting databases stored in your personal folders.

Uninstall PinDB

sudo apt remove pindb

Removing the application does not remove databases saved in your personal folders.

Troubleshooting

The package installer will not open the DEB.
Open a terminal in the download folder and use the apt install command above to see the full error.
APT says the package cannot be found.
Include ./ before the filename so APT knows you are installing a local file.
The automatic updater is unavailable.
Automatic installation requires pkexec and apt-get. You can still download and install a newer DEB manually.
Will uninstalling remove my databases?
No. PinDB databases stored in your home folder or other personal locations are not part of the application package.
