Debian, Ubuntu, and Linux Mint

Download the x86-64 DEB and matching checksum from the Download page.

sha256sum -c downloaded-package.deb.sha256
sudo apt install ./pindb_*_amd64.deb

The package is self-contained and includes PinDB's Java runtime.

Updates

PinDB downloads the matching DEB, verifies SHA-256, requests administrator approval, then uses its fixed root-owned update helper to securely stage and re-verify the package before apt-get installs it.

Uninstall

sudo apt remove pindb

Your separately stored .pindb database files are not part of the application package.
