Verify and install

sha256sum -c downloaded-package.deb.sha256
sudo apt install ./pindb_*_amd64.deb

Updates

On supported traditional Debian-family systems, PinDB downloads the matching DEB, verifies its published SHA-256 checksum, requests administrator approval, and uses its packaged update helper with the native package manager.

Uninstall

sudo apt remove pindb

User-created .pindb database files are separate from the application package.
