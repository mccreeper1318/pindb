Features

Portable databases

Every database is kept in one .pindb SQLite file. The file contains fields, entries, display choices, deleted records, internal backups, and embedded documents. Close the database before copying it between Windows and Linux.

Field types

FieldUse
TextNames, labels, identifiers, and short notes.
Multiline textLong descriptions and notes.
Number / CurrencyQuantities, totals, prices, and summaries.
Date / Date and timeAppointments, purchases, deadlines, and history.
Yes/NoSimple true-or-false information.
DropdownChoose from a controlled list of values.
DocumentStore a file directly inside the database.

Records and organization

  • Add, edit, and delete entries.
  • Use table view or record-card view.
  • Search across displayed values.
  • Sort columns and build field-specific filters.
  • Configure sum, average, minimum, maximum, or count summaries where supported.
  • Restore records from Recently Deleted.

Documents

A Document field stores the original file inside the database. PinDB can preview PDF, DOCX, text, and common image formats. Stored files can also be printed, saved as a copy, or opened in another application.

Printing, CSV, and backups

  • Print selected fields using column or record layouts.
  • Export visible entries to CSV.
  • Import a CSV file as a new database.
  • Keep timestamped internal backup snapshots.
  • Create an untouched safety copy before database migrations.
  • Checkpoint pending SQLite data during a normal close so the main .pindb file is portable.

Windows and Linux packages

Windows 11

Self-contained, per-user .exe installer for Windows 11 x64 beginning with 0.3 Beta 1.

Includes Start Menu integration, optional desktop shortcuts, install-directory selection, and .pindb file associations.

Debian-family Linux

Self-contained .deb package for Linux Mint, Ubuntu, Debian, and related systems.

Automatic installation uses the packaged privileged helper with apt-get.

Fedora-family Linux

Self-contained .rpm package for Fedora Workstation, Fedora KDE, and traditional Fedora spins.

Automatic installation uses the packaged privileged helper with dnf5 or dnf.

Every official package includes a private Java runtime, an application launcher, the PinDB icon, and a .pindb file association.

Update safety

  • Selects the native package type and architecture that match the current system.
  • Requires a matching published SHA-256 checksum before automatic installation.
  • On Windows, launches the verified per-user installer only after approval.
  • On traditional Linux systems, passes a securely staged package to the fixed privileged helper.
  • Restarts PinDB and preserves release notes after a successful Linux update.
  • Leaves pending release notes intact when another older PinDB instance starts during an update.

The Windows installer is currently unsigned, so Windows may display an unknown-publisher or SmartScreen reputation warning. Fedora Atomic desktops use a manual rpm-ostree installation path.
