Features

Portable personal databases

  • One portable .pindb file stores fields, entries, preferences, trash, internal backups, and embedded documents.
  • Open multiple databases in separate windows.
  • Automatic saving and WAL checkpointing during normal shutdown.
  • Pre-migration safety copies and diagnostics for damaged or unsupported databases.

Custom fields and validation

Text, multiline text, number, currency, date, date/time, yes/no, dropdown, and embedded-document fields are supported. Fields can use required-value rules, defaults, numeric ranges, uniqueness requirements, text limits, dropdown choices, and summaries where appropriate.

Entries and views

  • Add, edit, delete, restore, and permanently remove records.
  • Search across visible field values.
  • Sort columns and build field-specific filters.
  • Switch between spreadsheet-style table view and record cards.
  • Use Add & Add Another for repetitive entry.

Embedded documents

Original files are stored inside the database rather than as external paths. PinDB can preview PDF, DOCX, common text files, and images, and can save a copy, print supported previews, or open a file in its system application.

Summaries, CSV, and printing

  • Sum, average, minimum, maximum, and entry-count summaries where supported.
  • CSV import and export.
  • Column or record print layouts with portrait/landscape options.
  • Optional headings, database names, dates, page numbers, and summaries.
  • Print only the currently searched/filtered rows.

Backups and recovery

PinDB keeps timestamped logical backups inside each database, including embedded documents. Recently Deleted allows record recovery before permanent removal. External backups are still recommended for important data.

Cross-platform updates

PinDB checks GitHub Releases, selects the correct native installer, and requires a published SHA-256 checksum. Windows uses the x64 EXE; Debian/Fedora use native package managers through a fixed privileged helper; macOS uses architecture-specific Apple Silicon or Intel PKGs with protected root-owned staging before handing the verified package to macOS Installer.

Bug reporting

GitHub device authorization lets users submit bug reports from PinDB. Diagnostics are designed not to automatically include database contents, embedded documents, database filenames, or personal paths.
