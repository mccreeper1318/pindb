Features

Portable databases

Every database is kept in one .pindb SQLite file. The file contains fields, entries, display choices, deleted records, internal backups, and embedded documents.

Field types

FieldUse
TextNames, labels, identifiers, and short notes.
Multiline textLong descriptions and notes.
Number / CurrencyQuantities, totals, prices, and summaries.
Date / Date and timeAppointments, purchases, deadlines, and history.
Yes/NoSimple true-or-false information.
DropdownChoose from a controlled list of values.
DocumentStore a file directly inside the database.

Records and organization

  • Add, edit, and delete entries.
  • Use table view or record-card view.
  • Search across displayed values.
  • Sort columns and build field-specific filters.
  • Configure sum, average, minimum, maximum, or count summaries where supported.
  • Restore records from Recently Deleted.

Documents

A Document field stores the original file inside the database. PinDB can preview PDF, DOCX, text, and common image formats. Stored files can also be printed, saved as a copy, or opened in another application.

Printing, CSV, and backups

  • Print selected fields using column or record layouts.
  • Export visible entries to CSV.
  • Import a CSV file as a new database.
  • Keep timestamped internal backup snapshots.
  • Create an untouched safety copy before database migrations.
