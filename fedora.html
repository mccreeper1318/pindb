Fedora Workstation and Fedora spins

Download the x86-64 RPM and matching checksum from the Download page.

sha256sum -c downloaded-package.rpm.sha256
sudo dnf install ./pindb-*.x86_64.rpm

Updates on traditional Fedora

PinDB verifies the matching RPM, requests administrator approval, and uses its fixed root-owned helper to securely stage/re-verify the package before installing with dnf5 or dnf.

Fedora Atomic

Silverblue, Kinoite, and other immutable variants require manual layering and a reboot:

sudo rpm-ostree install ./pindb-*.x86_64.rpm

Uninstall

sudo dnf remove pindb

User-created .pindb files are separate from the application package.
