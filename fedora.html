PinDB on Fedora

RPM support begins with PinDB 0.2 Beta 4.

PinDB provides a self-contained .rpm package for 64-bit Fedora Workstation, Fedora KDE, and other traditional Fedora spins. The package includes a private Java runtime, so Java does not need to be installed separately for normal use.

GO TO FEDORA DOWNLOADS

Install on Fedora Workstation or a traditional spin

  1. Download the PinDB .rpm from the Download page.
  2. Double-click the RPM and open it with Software, Discover, or your package installer.
  3. Select Install and approve the administrator prompt.
  4. Launch PinDB from the application menu.

Terminal installation:

sudo dnf install ./pindb-*.x86_64.rpm

Automatic updates

On supported traditional Fedora installations, PinDB can download the matching RPM, verify its SHA-256 checksum when one is supplied, request administrator approval through pkexec, and install it with dnf5 or dnf.

Stable updates are checked by default. Beta updates can be enabled in PinDB Settings.

Fedora Silverblue, Kinoite, and other Atomic desktops

Automatic installation is not supported on Fedora Atomic desktops. These systems use rpm-ostree instead of the normal DNF installation path.

To layer the downloaded RPM manually:

sudo rpm-ostree install ./pindb-*.x86_64.rpm

Reboot into the new deployment after installing or updating PinDB with rpm-ostree.

Verify the downloaded RPM

Download the matching .sha256 file from the release and run:

sha256sum -c pindb-*.rpm.sha256

The check should report OK before you install the package.

What the RPM installs

  • The PinDB application and private Java runtime under /opt/pindb.
  • An application-menu shortcut.
  • The PinDB application icon.
  • A file association for .pindb databases.

Uninstall PinDB

sudo dnf remove pindb

Removing the application does not remove databases saved in your personal folders.

Troubleshooting

The RPM will not install.
Confirm that you downloaded the x86-64 RPM and try the terminal command above so DNF can display the full error.
The automatic updater is unavailable.
Automatic installation requires a traditional Fedora installation, pkexec, and either dnf5 or dnf.
I use Silverblue or Kinoite.
Use the manual rpm-ostree command and reboot. PinDB intentionally does not run DNF on Atomic desktops.
