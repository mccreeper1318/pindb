Build PinDB on macOS

Requirements

  • macOS development environment
  • Git
  • JDK 25 with jpackage
  • Native hardware matching the package architecture you want to create

Clone and test

git clone https://github.com/mccreeper1318/pindb.git
cd pindb
git switch dev
chmod +x gradlew
./gradlew clean test

Run from source

./gradlew run

Create a native PKG

Replace <version> with the version you are building.

./gradlew clean test packageMacPkg -PappVersion=<version>

Build the ARM64 package on Apple Silicon and the x64 package on Intel hardware. Native package output is written under build/packages/ and includes a private Java runtime.

Official release builds

The project uses native Apple Silicon and Intel runners so official release packages are built and checked on the architecture they target.
